# 🎨 AI Image-to-Sketch Converter
A professional-grade Python tool that transforms standard photographs into realistic pencil sketches using Computer Vision.

## 🚀 Overview
This project was built to demonstrate the power of local image processing without relying on expensive cloud APIs. It features a clean, interactive user interface and high-speed processing logic.

## ✨ Key Features
- **Instant Transformation:** Converts images in real-time.
- **Smart Edge Detection:** Uses Gaussian Blur and Dodge Blending for a realistic pencil effect.
- **Interactive UI:** Built with Streamlit for a seamless "Upload & Download" workflow.
- **Privacy First:** All processing happens locally on your machine.

## 🛠️ Tech Stack
- **Language:** Python 3.14
- **Computer Vision:** OpenCV
- **Front-end Framework:** Streamlit
- **Image Handling:** Pillow & NumPy
